# real-estate-crm

Simplesphere OS — Luxury Real Estate CRM Cockpit

Built with high-end architectural aesthetics, live telemetry, inventory management, dynamic cost sheets, RERA compliance, Jarvis AI voice telephony, and multi-touch marketing attribution.

## Features
- **Architectural Inventory Matrix**: 3D Stacking Plan, real-time lock protocol, floor-rise & PLC computation.
- **Sales Funnel & Kanban Pipeline**: Dynamic stages, Jarvis AI intent scoring, instant communication triggers.
- **Dynamic Cost Sheet Engine**: MahaRERA-compliant calculations, 5% GST, 6% Stamp Duty, Construction-Linked Payment (CLP) milestones.
- **Field Ops & Geofenced Site Visits**: 250m Haversine geo-checkin, chauffeur valet tracking.
- **Post-Sales & CLP Collections**: RERA Section 11(4)(g) escrow ledger, architect sign-off certificates.
- **Marketing Attribution & Multi-Touch UTM Tracking**: First-touch, mid-touch, and last-touch conversion modeling.
- **Channel Partner (Broker) Platform**: Section 194H 5% TDS calculator and digital passbook.
- **Homebuyer CX Portal**: Live 1080p construction camera telemetry, encrypted DigiLocker locker, dedicated RM liaison.
- **IRIS Launch War Room**: Real-time launch floor feed, algorithmic yield controller with dynamic price-rise triggers.
- **Jarvis AI Voice Studio**: Bilingual English & Hindi autonomous inbound/outbound buyer qualification.

## Getting Started
```bash
npm install
npm start
```
Run verification tests:
```bash
node test.js
```
